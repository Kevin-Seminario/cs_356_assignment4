# World 3 regional transit buyer offers

Five separate one-round agreement files are ready for human review and upload.
They are a pilot inventory, not evidence that signing all five improves the
live score. Review each buyer's alternative routes, likely bilateral volume,
and the supplier routes we can actually retain. The $400 payments in local
starter-opponent models are cap-limited; they are not forecasts of live
receipts or proof of a $2,000 gain.
Each buyer pays jknetwork $1 per Mb crossing their bilateral link in either
direction, capped at $400 per round. The agreement renews for one round unless
either party declines. It opens a transit relationship; the switch's routing
policy determines which destinations jknetwork announces and carries.

Before uploading, check the site's live agreement list. Existing old-form
free-peer agreements with a buyer should end at the Round 3 cutoff; do not
sign a new free-peer replacement with the same buyer for the same round.
Likewise, do not duplicate an already signed new-format transit file.
The proposed service is useful only if jknetwork retains routes to the other
side, especially Claude 1 and Lucky Comets, and its switch carries those
routes. These files charge for bilateral traffic even if it arrives late or
is lost; they contain no quality refund. Make that term clear to buyers.

Local check: all five compiled for `wasm32-unknown-unknown`. In a matched
World 3 full-ring practice run with the published Round 3-shaped storm,
all five settled without error and produced exactly the same utility as
the generic $1/Mb, $400-cap transit agreements they replace. The model uses
starter opponents and is not a live revenue prediction.
